# 🔁 Vorgangspassiv — Das werden-Passiv

> Das **Vorgangspassiv** (auch: *werden-Passiv*) beschreibt eine **Handlung** oder einen Prozess, der am Subjekt vollzogen wird — das Subjekt ist **nicht** der Handelnde, sondern der **Empfänger** der Handlung.

Aktiv: *Der Koch **kocht** das Essen.* → Der Koch handelt.
Passiv: *Das Essen **wird** gekocht.* → Das Essen erfährt die Handlung.

---

## Formel

| Struktur | Beispiel |
|----------|---------|
| Subjekt + **werden** (konj.) + … + **Partizip II** | *Das Buch **wird** gelesen.* |
| Mit Akteur: + **von** + Dativ | *Das Buch wird **vom** Lehrer gelesen.* |

---

## Konjugation von *werden* (Präsens)

| Person | Form |
|--------|------|
| ich | werde |
| du | wirst |
| er / sie / es | **wird** |
| wir | werden |
| ihr | werdet |
| sie / Sie | werden |

---

## Tempora im Vorgangspassiv

| Tempus | Bildung | Beispiel |
|--------|---------|---------|
| **Präsens** | werden (Präs.) + Partizip II | *Das Essen **wird** gekocht.* |
| **Präteritum** | werden (Prät.) + Partizip II | *Das Essen **wurde** gekocht.* |
| **Perfekt** | sein (Präs.) + Partizip II + **worden** | *Das Essen **ist** gekocht **worden**.* |
| **Plusquamperfekt** | sein (Prät.) + Partizip II + **worden** | *Das Essen **war** gekocht **worden**.* |
| **Futur I** | werden (Präs.) + Partizip II + **werden** | *Das Essen **wird** gekocht **werden**.* |

> [!warning] Achtung — Perfekt
> Im Passiv-Perfekt steht **worden** (nicht *geworden*).
> *Das Haus ist gebaut **worden**.* ✓  
> *Das Haus ist gebaut **geworden**.* ✗

---

## Aktiv → Passiv Umwandlung

| Aktiv | → | Passiv |
|-------|---|--------|
| Akkusativ-Objekt | → | Subjekt (Nominativ) |
| Subjekt (Akteur) | → | **von** + Dativ *(oft weggelassen)* |
| konjugiertes Verb | → | **werden** (konj.) + Partizip II |

**Aktiv:** *Der Mechaniker **repariert** **den Motor**.*
**Passiv:** ***Der Motor** **wird** (vom Mechaniker) **repariert**.*
**Ohne Akteur:** *Der Motor wird repariert.*

---

## Wann benutzt man Passiv?

| Situation | Beispiel |
|-----------|----------|
| Der Akteur ist **unbekannt** | *Mein Fahrrad wurde gestohlen.* |
| Der Akteur ist **offensichtlich** | *In Deutschland wird Deutsch gesprochen.* |
| Die **Handlung** ist wichtiger als der Akteur | *Die Brücke wurde 1950 gebaut.* |
| Formale / wissenschaftliche Texte | *Die Probe wurde auf 80°C erhitzt.* |

---

## Übung: Aktiv → Passiv

1. Der Schüler liest das Buch. → *Das Buch wird (vom Schüler) gelesen.*
2. Die Firma baut eine neue Fabrik. → *Eine neue Fabrik wird (von der Firma) gebaut.*
3. Der Arzt hat den Patienten untersucht. → *Der Patient ist (vom Arzt) untersucht worden.*
4. Man spricht hier Spanisch. → *Hier wird Spanisch gesprochen.*
5. Die Polizei wird den Täter fangen. → *Der Täter wird (von der Polizei) gefangen werden.*

---

## Vorgangspassiv vs. Zustandspassiv

| | Vorgangspassiv (werden) | Zustandspassiv (sein) |
|---|---|---|
| **Fokus** | Die Handlung / der Prozess | Das Resultat / der Zustand |
| **Bildung** | werden + Partizip II | sein + Partizip II |
| **Beispiel** | *Die Tür **wird** geöffnet.* (jemand öffnet sie) | *Die Tür **ist** geöffnet.* (sie ist offen) |
