## ¿Qué es AS9100?

AS9100 es el estándar de calidad específico para la industria aeroespacial, basado en [[ISO 9001]] pero con requisitos adicionales para seguridad, trazabilidad y gestión de riesgos. NAXCON opera bajo este estándar para el programa F-35.

| Aspecto | Diferencia con ISO 9001 |
|---------|------------------------|
| **Trazabilidad** | Cada pieza requiere genealogía completa — serial number, lote, operador, máquina, fecha |
| **Gestión de riesgos** | Análisis de riesgos obligatorio en diseño y producción (no solo correctivo) |
| **Control de cambios** | Cualquier cambio en proceso requiere aprobación del cliente (Lockheed Martin) |
| **First Article Inspection** | Cada nuevo componente requiere FAIR antes de producción en serie |
| **Configuración** | Control estricto de revisiones de dibujos y especificaciones |

## Relevancia para el rol

Como Junior Process Engineer en NAXCON, trabajarás bajo AS9100:

- **Documentación de procesos** — cada work instruction debe cumplir [[AS9102]] (First Article)
- **Control de no-conformidades** — reportes [[8D]], [[root cause analysis]], [[corrective actions]]
- **Auditorías internas** — soporte a auditorías de calidad AS9100
- **Trazabilidad serial** — asegurar que cada parte F-35 tenga registro completo birth-to-death

## Conexión con otros conceptos

- [[MES]] rastrea la trazabilidad que AS9100 exige
- [[Discrete Manufacturing]] produce las unidades contables que AS9100 audita
- [[Automation Commissioning]] debe validarse bajo AS9100 antes de liberar una work cell

> [!tip] Transferibilidad
> AS9100 es más riguroso que API Q1 / ASME (Oil & Gas). Dominarlo te posiciona para roles en toda la cadena aeroespacial (Airbus, Boeing, Tier-1 suppliers).
